# GeoConnect Hub

This is a file upload sharing web application for users to signup and login to add new places to share for other users. This project uses the MERN stack technology to build and develop the frontend using React.js, the backend using Node.js and Express.js, and the database using MongoDB. The users are able to view the map location of each place that's uploaded to the web application as well as having authorization for managing their own places by updating it or deleting it. It's an easy lightweight web application for sharing images of places that are of significance to the user sharing it.

## Viewing Web Application

There are two methods to view the web application. You can either click on the link to view the web application or follow the instructions below to run it locally.

Link: www.geoconnecthub.com

## Run Locally using git

Clone the project

```bash
  git clone https://github.com/VkProjects907/GeoConnect-Hub.git
```

Go to the project folder directory

```bash
cd ./GeoConnect-Hub
```

Go to the project directory

```bash
  cd ./Frontend/
  cd ./Backend/
```

Install dependencies

```bash
  npm install
```

Start the server

```bash
  npm start
```
